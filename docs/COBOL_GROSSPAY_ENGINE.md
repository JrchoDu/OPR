# GROSSPAY module

Purpose: sum gross earnings. Inputs: basic pay, overtime, taxable allowance, other allowance, bonus, and commission as `PIC 9(9)V99`. Output: gross pay at two decimal places. Copybooks/configuration: none. Formula: sum all six inputs with `COMPUTE ... ROUNDED`; taxability classification remains a separate verified-rule concern. Flow: one fixed-decimal calculation and return. Error handling: caller validates each input as non-negative. Example: 50,000 + 3,000 + 2,000 = 55,000. Compile: include `GROSSPAY.CBL` with engine sources. Test: caller should test zeros and decimal values. Java call: through the coordinator after it is wired. Common errors: passing employer contribution or non-earning deductions as an earning. Future: separate taxable and non-taxable summaries.
