# TEST-RULE-MODULES program

Purpose: test the arithmetic contracts of SSSCALC, PHILHEALTH, PAGIBIG and TAXCALC. Inputs: test-only synthetic salaries, bracket bounds, contribution amounts/rates and taxable compensation. Outputs: `PASS SYNTHETIC RULE MODULE ARITHMETIC` or a named failure and non-zero return. Data structures: linkage layouts intentionally match each production subprogram. Copybooks: none. Configuration files: none; values are synthetic and are not government rules. Formula coverage: inclusive bracket selection, floor/ceiling bounded base and share splits, maximum-base cap and percentage, and base-tax-plus-excess bracket computation. Program flow: initialize synthetic rows, call each module, assert expected decimal values. Error handling: stop at first failed assertion. Example: synthetic tax 500 + (20,000 - 10,000) × 10% = 1,500. Compile/test: `scripts/test-cobol.*`. Java call: never; this is a test executable. Common errors: treating test values as official rates or changing the linkage layout without updating the fixture. Future: add source-verified statutory boundary cases after official tables are approved.
